# i3

## Qué es

Window manager de mosaico (tiling): las ventanas se organizan automáticamente sin superponerse, optimizando el espacio disponible. Sin decoraciones pesadas, sin drag & drop con mouse — todo se controla por teclado. Muy popular como punto de entrada al mundo tiling por su curva de aprendizaje relativamente suave, su documentación clara y su estabilidad.

## Instalación

```bash
# Debian/Ubuntu
sudo apt install i3 i3status i3lock dmenu   # WM + barra + bloqueo + lanzador

# Arch
sudo pacman -S i3-wm i3status i3lock dmenu

# Fedora
sudo dnf install i3 i3status i3lock dmenu
```

## Configuración inicial

- Archivo de config: `~/.config/i3/config` (texto plano). Se genera un archivo de ejemplo con Wizard la primera vez que se inicia i3.
- Barra de estado: `i3status` (simple, texto plano) o `polybar` (más vistosa, con módulos de red, batería, fecha, etc.).

### Polybar (alternativa popular a i3status)

```bash
sudo apt install polybar                   # Debian/Ubuntu
sudo pacman -S polybar                     # Arch
# Config: ~/.config/polybar/config.ini
```

### i3-gaps (gaps entre ventanas)

Históricamente i3 no tenía espacios entre ventanas; existía un fork llamado `i3-gaps`. Desde **i3 v4.22** (2022), los gaps se incorporaron oficialmente:

```bash
# Configurar gaps en ~/.config/i3/config:
gaps inner 10                             # espacio entre ventanas
gaps outer 5                              # espacio entre ventanas y bordes de pantalla
```

## Workspaces y contenedores

i3 organiza las ventanas en **workspaces** (espacios de trabajo) y dentro de cada workspace usa **contenedores** con layouts:

```bash
# Layouts de contenedores:
# - split horizontal (default): ventanas lado a lado
# - split vertical: ventanas apiladas verticalmente
# - stacked: ventanas en pestañas con barra de título
# - tabbed: ventanas en pestañas sin barra de título
```

## Atajos de teclado clave

| Atajo | Acción |
|---|---|
| `Mod + Enter` | Abrir terminal |
| `Mod + D` | Lanzador de apps (dmenu/rofi) |
| `Mod + J/K/L/Ñ` (o flechas) | Moverse entre ventanas |
| `Mod + Shift + J/K/L/Ñ` | Mover ventana en dirección |
| `Mod + V` | Siguiente ventana en vertical (split vertical) |
| `Mod + H` | Siguiente ventana en horizontal |
| `Mod + F` | Pantalla completa (toggle) |
| `Mod + Shift + Q` | Cerrar ventana |
| `Mod + Shift + E` | Salir de i3 |
| `Mod + R` | Modo resize (flechas para redimensionar, Enter/Esc para salir) |
| `Mod + 1-9` | Ir al workspace N |
| `Mod + Shift + 1-9` | Mover ventana al workspace N |
| `Mod + Shift + Space` | Toggle flotante (floating/tiling) |

(`Mod` suele ser la tecla `Super`/Windows por defecto, configurable en el config)

## Multi-monitor

```bash
# En ~/.config/i3/config:
workspace 1 output HDMI-1                # workspace 1 siempre en el monitor HDMI
workspace 2 output eDP-1                 # workspace 2 en el portátil

# Atajos para mover entre monitores:
# Mod + Flecha izquierda/derecha → mover foco al monitor contiguo
# Mod + Shift + Flecha → mover ventana al otro monitor
```

```bash
# Detectar nombres de salida:
xrandr --current | grep " connected"
```

## Modo resize

Presiona `Mod + R` para entrar en modo resize: las flechas redimensionan la ventana activa. Presiona `Enter` o `Esc` para salir del modo. Es un "modo" de i3, por lo que los atajos habituales de navegación quedan temporalmente reemplazados.

```bash
# Mod + R → (flechas) → Enter
```

## Pros / Contras

- ✅ Muy rápido, estable, config declarativa fácil de versionar en git.
- ✅ Documentación excelente (User Guide en i3wm.org).
- ✅ Funciona igual en X11 (Wayland no soportado nativamente — para Wayland probar [[Hyprland]] o [[Niri]]).
- ❌ Sin efectos visuales ni animaciones (ni se esperan).
- ❌ Requiere configurar manualmente barra, compositor (picom), wallpaper (feh), lanzador (dmenu/rofi).
- ❌ No es touchpad-friendly (todo por teclado).

## Notas personales

- i3 es el WM que recomiendo a todo el que quiere probar tiling por primera vez. La documentación (User Guide) es la mejor de cualquier WM — clara, completa, con ejemplos.
- Los gaps se incorporaron oficialmente en i3 v4.22 (2022), pero mucha gente todavía piensa que necesita i3-gaps. ¡Ya no! Usa i3 directamente.
- i3 no tiene Wayland. Si tu hardware es moderno (GPU con aceleración 3D), Sway es el reemplazo natural con la misma configuración. Pero si usas NVIDIA, i3 en X11 sigue siendo más fiable.
- i3 sigue siendo el WM más usado en r/unixporn y por una razón: hace lo que promete, sin sorpresas, desde 2009.
