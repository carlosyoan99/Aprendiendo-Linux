# Geany

## Qué es

Geany es un **IDE ligero** basado en GTK. Ideal para programación ocasional en equipos modestos o para quienes buscan algo más que un editor de texto pero menos que un IDE completo.

```bash
sudo apt install geany            # Debian/Ubuntu
sudo pacman -S geany              # Arch
```

## Características clave

- **Ligero** — ~15 MB de RAM, arranque instantáneo
- **Soporte de múltiples lenguajes** — resaltado sintáctico, plegado de código
- **Terminal integrada**
- **Sistema de proyectos** — carpetas y archivos organizados
- **Plugins** — soporte básico de extensiones
- **LSP básico** — autocompletado limitado (vía plugins)
