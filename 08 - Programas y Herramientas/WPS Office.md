# WPS Office

Suite ofimática propietaria de origen chino con interfaz muy similar a Microsoft Office 2013-2019. Compatibilidad OOXML excelente. La versión gratuita incluye anuncios (configurables).

## Instalación

```bash
# Arch
yay -S wps-office

# O descargar .deb desde: https://www.wps.com/

# Diccionarios en español
yay -S wps-office-mui-spanish            # interfaz en español
yay -S wps-office-extension-spanish-dictionary  # corrector
```

## Ventajas

- Interfaz muy familiar para usuarios de MS Office
- Rápida y ligera (~200 MB)
- Excelente compatibilidad OOXML

## Desventajas

- Propietaria (código cerrado)
- Anuncios en versión gratuita
- Requiere cuenta WPS para algunas funciones
- Disponible en AUR pero no en repos oficiales
