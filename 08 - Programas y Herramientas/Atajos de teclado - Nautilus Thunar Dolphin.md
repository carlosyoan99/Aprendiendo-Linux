# Atajos de teclado - Gestores de archivos

> Accesos rápidos **por defecto** de los tres gestores de archivos con entorno gráfico más usados en Linux: **Nautilus** (Files, GNOME/GTK), **Thunar** (XFCE/GTK) y **Dolphin** (KDE/Qt). Los atajos de portapapeles y navegación son muy similares entre los tres.

## Navegación y ventanas

| Atajo | Nautilus | Thunar | Dolphin | Efecto |
|---|---|---|---|---|
| `Ctrl+L` | ✓ | ✓ | ✓ | Mostrar barra de ubicación (ruta) |
| `Ctrl+T` | ✓ | ✓ | ✓ | Nueva pestaña |
| `Ctrl+W` | ✓ | ✓ | ✓ | Cerrar pestaña |
| `Ctrl+N` | ✓ | ✓ | ✓ | Nueva ventana |
| `Ctrl+Shift+W` | ✓ | — | ✓ | Cerrar ventana |
| `Alt+←` / `Alt+→` | ✓ | ✓ | ✓ | Atrás / adelante en historial |
| `Alt+↑` | ✓ | ✓ | ✓ | Subir a la carpeta padre |
| `Ctrl+D` | ✓ | ✓ | ✓ | Añadir a marcadores (bookmark) |
| `Ctrl+1 / 2 / 3` | ✓ | — | ✓ | Vista iconos / lista / detalle |

## Archivos y portapapeles

| Atajo | Efecto |
|---|---|
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copiar / cortar / pegar |
| `Ctrl+Shift+N` | Crear carpeta nueva |
| `Ctrl+A` | Seleccionar todo |
| `Shift+Click` | Seleccionar rango |
| `Ctrl+Click` | Seleccionar múltiples sueltos |
| `Espacio` | Previsualizar (peek preview) |
| `F2` | Renombrar archivo seleccionado |
| `Supr` / `Delete` | Mover a la papelera |
| `Ctrl+Shift+Supr` | Borrar definitivamente (Nautilus: shift+Supr) |
| `Ctrl+E` | Abrir con aplicación (Nautilus) |
| `Ctrl+Enter` | Abrir ubicación en nueva pestaña (Thunar) |

## Búsqueda y ubicación

| Atajo | Nautilus | Thunar | Dolphin | Efecto |
|---|---|---|---|---|
| `Ctrl+F` | ✓ | ✓ | ✓ | Buscar |
| `/` | ✓ | ✓ | — | Ir a ubicación por ruta |
| `Ctrl+H` | ✓ | — | ✓ | Mostrar archivos ocultos |
| `F3` | ✓ | - | ✓ | Panel dividido (Thunar F3, Dolphin F3) |
