# FreeOffice

Versión gratuita de **SoftMaker Office**. Interfaz clásica, compatible con formatos MS Office, sin coste de licencia.

## Instalación

```bash
# Descargar .deb o .rpm desde:
# https://www.freeoffice.com/en/download
```

## Características

- Compatibilidad con formatos MS Office (.docx, .xlsx, .pptx)
- Interfaz clásica con pestañas y cintas de opciones
- Incluye procesador de textos (TextMaker), hoja de cálculo (PlanMaker) y presentaciones (Presentations)
- Versión de pago: SoftMaker Office (funciones adicionales)
