# OnlyOffice

Suite ofimática moderna con excelente compatibilidad con formatos MS Office. Escrita en HTML5/JS, funciona en Linux, Windows y macOS. Ideal para entornos donde la fidelidad con `.docx`/`.xlsx` es crítica.

## Instalación

```bash
# Flatpak (recomendado)
flatpak install flathub org.onlyoffice.desktopeditors

# O descargar .deb/.rpm desde:
# https://www.onlyoffice.com/download-desktop.aspx
```

## Ventajas

- Mejor compatibilidad OOXML del mercado (⭐⭐⭐⭐⭐)
- Interfaz moderna y limpia
- Colaboración en tiempo real
- Ligera (~300 MB)
- Licencia AGPL (libre)

## Desventajas

- Sin base de datos integrada
- Sin macros tan potentes como LibreOffice
- Menos funcionalidades avanzadas
