# Atajos de teclado - Firefox

> Accesos rápidos **por defecto** del navegador Mozilla Firefox (Linux). Se personalizan (o desactivan) desde Ajustes → Teclado o con la extensión **Shortkeys**.

## Navegación y barra de direcciones

| Atajo | Efecto |
|---|---|
| `Ctrl+L` | Ir a la barra de direcciones (selecciona todo) |
| `Ctrl+K` | Barra de búsqueda (si está separada); si no, busca en la barra |
| `Ctrl+E` | Igual que `Ctrl+K` |
| `F6` | Alternar foco url-barra / página |
| `Ctrl+T` | Nueva pestaña |
| `Ctrl+W` | Cerrar pestaña actual |
| `Ctrl+Shift+T` | Reabrir última pestaña cerrada |
| `Ctrl+Tab` | Siguiente pestaña |
| `Ctrl+Shift+Tab` | Pestaña anterior |
| `Ctrl+1..8` | Ir a pestaña 1..8 |
| `Ctrl+9` | Ir a la última pestaña |
| `Ctrl+Shift+PgDn` | Mover pestaña a la derecha |
| `Ctrl+Shift+PgUp` | Mover pestaña a la izquierda |
| `Ctrl+Shift+N` | Nueva ventana privada |
| `Ctrl+N` | Nueva ventana normal |
| `Alt+←` / `Alt+→` | Atrás / Adelante |
| `Alt+Inicio` | Ir a la página de inicio |
| `F5` / `Ctrl+R` | Recargar página |
| `Ctrl+Shift+R` | Recarga forzada (ignora caché) |
| `Esc` | Detener carga |
| `Home` / `End` | Inicio / fin de página |
| `Space` / `Shift+Space` | Bajar / subir una página (Page Down/Up) |

## Búsqueda dentro de la página

| Atajo | Efecto |
|---|---|
| `Ctrl+F` | Buscar en la página |
| `Ctrl+G` | Siguiente resultado |
| `Ctrl+Shift+G` | Resultado anterior |
| `/` | Búsqueda rápida (solo enlaces, si está activada) |
| `'` | Búsqueda de texto (teclea directamente) |

## Historial, marcadores y descargas

| Atajo | Efecto |
|---|---|
| `Ctrl+H` | Abrir historial lateral |
| `Ctrl+B` | Mostrar/ocultar barra de marcadores |
| `Ctrl+Shift+B` | Administrador de marcadores (library) |
| `Ctrl+D` | Añadir página a marcadores |
| `Ctrl+Shift+D` | Marcar todas las pestañas |
| `Ctrl+J` | Descargas |
| `Ctrl+Shift+Del` | Borrar historial reciente |

## Zoom, texto y modo lectura

| Atajo | Efecto |
|---|---|
| `Ctrl+[-]` / `Ctrl+[+]` | Disminuir / aumentar zoom de página |
| `Ctrl+0` | Restablecer zoom (100%) |
| `Ctrl+=` | Aumentar zoom |
| `Ctrl+Shift+Y` | Modo lectura (Reader View) |
| `Alt+V` → `Alt+V` | Vista de archivo (menú) |

## DevTools y funciones avanzadas

| Atajo | Efecto |
|---|---|
| `F12` / `Ctrl+Shift+I` | Abrir herramientas de desarrollador |
| `Ctrl+Shift+C` | Inspeccionar elemento |
| `Ctrl+Shift+J` | Consola del navegador |
| `Ctrl+Shift+E` | Herramienta de red |
| `Ctrl+M` | Silenciar la pestaña actual |
| `Ctrl+Shift+W` | Cerrar ventana |
| `Ctrl+P` | Imprimir |
| `Ctrl+S` | Guardar página |
| `Ctrl+=` | Acercar (duplicado de `Ctrl++`) |
