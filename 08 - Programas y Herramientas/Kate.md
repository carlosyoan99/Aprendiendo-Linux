# Kate

## Qué es

Kate es el editor de texto avanzado del **entorno KDE Plasma**. Multipestaña, muy completo, con LSP integrado y una amplia gama de funcionalidades que lo sitúan a medio camino entre un editor de texto y un IDE.

```bash
sudo apt install kate             # Debian/Ubuntu
sudo pacman -S kate               # Arch
# Viene con KDE Plasma por defecto
```

## Características clave

- **Multipestaña** — edición de múltiples archivos en pestañas
- **LSP integrado** — autocompletado, diagnóstico, ir a definición
- **Terminal integrada**
- **Resaltado sintáctico** — soporte para cientos de lenguajes
- **Sistema de proyectos** — vista de carpetas, búsqueda en proyecto
- **Integración con KDE** — sigue el tema y atajos del escritorio
- **Vi mode** — modo Vim básico integrado
