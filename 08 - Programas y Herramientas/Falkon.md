# Falkon

## Qué es

**Falkon** (antes QupZilla) es un navegador web ligero basado en **Qt WebEngine** (Blink). Es el navegador por defecto en algunos entornos KDE/Qt. Destaca por su bajo consumo de recursos y su integración con el escritorio KDE.

## Instalación

```bash
sudo apt install falkon                 # Debian/Ubuntu
sudo pacman -S falkon                   # Arch
flatpak install flathub org.kde.falkon
```
