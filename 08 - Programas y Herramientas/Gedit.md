# Gedit

## Qué es

Gedit es el editor de texto oficial del **entorno GNOME**. Simple, limpio y minimalista — ideal para ediciones rápidas con interfaz gráfica sin distracciones.

```bash
sudo apt install gedit            # Debian/Ubuntu
sudo pacman -S gedit              # Arch
# Viene con GNOME por defecto
```

## Características clave

- **Simple y limpio** — interfaz GNOME sin distracciones
- **Multipestaña**
- **Resaltado sintáctico** — soporte para múltiples lenguajes
- **Plugins** — desde el gestor de plugins de GNOME
- **Búsqueda y reemplazo** — con soporte de expresiones regulares
- **Integración con GNOME** — sigue el tema y atajos del escritorio
