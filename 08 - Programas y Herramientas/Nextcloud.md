# Nextcloud

> Plataforma self-hosted de productividad y almacenamiento en la nube. Alternativa a Google Drive, Dropbox y Office 365 con control total de tus datos.

## Qué es

Nextcloud es una suite de software libre para montar tu propia nube privada: archivos, calendario, contactos, correo, videollamadas, colaboración en documentos (Nextcloud Office) y más. Se instala en un servidor Linux con PHP y una base de datos (PostgreSQL, MySQL o SQLite).

## Instalación rápida (Docker)

```bash
docker run -d -p 8080:80 nextcloud
# Acceder en http://localhost:8080
```
