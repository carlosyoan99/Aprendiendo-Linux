# Thunar

Gestor de archivos por defecto de [[XFCE]]. Ligero, rápido y sencillo, ideal para equipos con pocos recursos o para usar en WMs minimalistas donde se prefiere una GUI ligera.

## Instalación

```bash
sudo apt install thunar          # Debian/Ubuntu
sudo pacman -S thunar            # Arch
sudo dnf install thunar          # Fedora
```

## Atajos clave

| Atajo | Acción |
|---|---|
| `Ctrl+T` | Nueva pestaña |
| `Ctrl+F` | Buscar |
| `Ctrl+D` | Marcar favorito |
| `F2` | Renombrar |

## Características

- Ligero y rápido (~15 MB RAM)
- Pestañas
- Búsqueda básica
- Renombrado batch (con complemento `thunar-renamer`)
- Puede instalarse independientemente del DE (funciona en cualquier WM)
- Complementos útiles: `thunar-archive-plugin`, `thunar-media-tags-plugin`, `thunar-volman`

## Ventajas

- Excelente rendimiento incluso en equipos muy lentos
- Sin dependencias pesadas
- Configuración simple e intuitiva
