# Xfce Terminal

Terminal por defecto del entorno [[XFCE]]. Ligera, rápida y con lo justo: pestañas, perfiles y configuración simple sin depender de GNOME o KDE.

## Instalación

```bash
sudo apt install xfce4-terminal    # Debian/Ubuntu
sudo pacman -S xfce4-terminal      # Arch
sudo dnf install xfce4-terminal    # Fedora
```

## Características

- Pestañas nativas
- Ligera (~15 MB RAM) — ideal para equipos con pocos recursos
- Perfiles de configuración
- Transparencia y fondo de imagen
- Atajos de teclado configurables
- Sin dependencias de GNOME o KDE

## Configuración

Se configura desde **Editar → Preferencias** en la interfaz gráfica. Los atajos se personalizan desde **Editar → Atajos de teclado**.
