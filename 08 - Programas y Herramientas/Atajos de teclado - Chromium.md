# Atajos de teclado - Chromium

> Accesos rápidos **por defecto** de los navegadores basados en Chromium: **Chromium, Google Chrome, Brave, Edge, Vivaldi, Ungoogled Chromium**. La mayoría son idénticos entre sí; las diferencias se señalan. Se personalizan en `chrome://settings/shortcuts`.

## Pestañas y ventanas

| Atajo | Efecto |
|---|---|
| `Ctrl+T` | Nueva pestaña |
| `Ctrl+Shift+T` | Reabrir última pestaña cerrada |
| `Ctrl+W` | Cerrar pestaña actual |
| `Ctrl+Shift+W` | Cerrar ventana |
| `Ctrl+N` | Nueva ventana |
| `Ctrl+Shift+N` | Nueva ventana incógnito |
| `Ctrl+Tab` | Siguiente pestaña |
| `Ctrl+Shift+Tab` | Pestaña anterior |
| `Ctrl+1..8` | Ir a pestaña 1-8 |
| `Ctrl+9` | Ir a la última pestaña |
| `Ctrl+Shift+PgDn/PgUp` | Mover pestaña a derecha / izquierda |
| `Ctrl+Click` | Abrir enlace en nueva pestaña |
| `Ctrl+Shift+Click` | Abrir enlace en nueva pestaña y enfocar |
| `Ctrl+L` / `F6` / `Alt+D` | Ir a la barra de direcciones |
| `F11` | Pantalla completa |

## Navegación

| Atajo | Efecto |
|---|---|
| `Alt+←` / `Alt+→` | Atrás / Adelante |
| `Alt+Home` | Página de inicio |
| `F5` / `Ctrl+R` | Recargar página |
| `Ctrl+Shift+R` / `Ctrl+F5` | Recarga forzada (sin caché) |
| `Esc` | Detener carga |
| `Ctrl+Shift+Delete` | Borrar datos de navegación |
| `Ctrl+H` | Historial |
| `Ctrl+J` | Descargas |
| `Home` / `End` | Inicio / fin de página |
| `Space` / `Shift+Space` | Página abajo / arriba |
| `PgDn` / `PgUp` | Página abajo / arriba |
| `Alt+Space+N` | Minimizar ventana |
| `Alt+Space+X` | Maximizar ventana |
| `Alt+Space+C` / `Alt+F4` | Cerrar ventana |

## Búsqueda y omnibox

| Atajo | Efecto |
|---|---|
| `Ctrl+F` | Buscar en la página |
| `Ctrl+G` / `Enter` | Siguiente resultado |
| `Ctrl+Shift+G` | Resultado anterior |
| `Ctrl+K` | Buscar con Google (omnibox) |
| `Ctrl+E` | Igual que `Ctrl+K` |
| `Ctrl+D` | Añadir a marcadores |
| `Ctrl+Shift+D` | Marcar todas las pestañas |
| `Ctrl+Shift+O` | Administrador de marcadores |
| `Ctrl+Shift+B` | Mostrar/ocultar barra de marcadores |

## Edición y clipboard

| Atajo | Efecto |
|---|---|
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copiar / Cortar / Pegar |
| `Ctrl+Shift+V` | Pegar como texto plano (en omnibox) |
| `Ctrl+Z` | Deshacer |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+F5` | Pegar y buscar (en omnibox) |

## Zoom y visualización

| Atajo | Efecto |
|---|---|
| `Ctrl++` / `Ctrl+-` | Aumentar / disminuir zoom |
| `Ctrl+0` | Restablecer zoom (100%) |
| `Ctrl+Shift+P` | Modo reader (reader mode, solo Chromium) |
| `Ctrl+Shift+J` | Abrir Developer Tools (consola) |
| `F12` | Abrir Developer Tools |
| `Ctrl+Shift+I` | Abrir Developer Tools (inspector) |
| `Ctrl+Shift+C` | Inspeccionar elemento |
