# Brave

## Qué es

**Brave** es un navegador basado en Chromium/Blink con bloqueo de anuncios y rastreadores integrado. Incluye recompensas BAT (Basic Attention Token) y un firewall/VPN integrado. Es conocido por su enfoque en privacidad sin sacrificar compatibilidad con Chrome.

## Instalación

```bash
flatpak install flathub com.brave.Browser
# O desde AUR:
yay -S brave-bin
```

## Gestión de perfiles

```bash
ls ~/.config/BraveSoftware/
brave --user-data-dir=~/.config/brave-trabajo
```
