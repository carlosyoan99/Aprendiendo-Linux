# Lapce

## Qué es

Editor nativo escrito en **Rust** con renderizado por GPU (usando Druid / Floem), compatible con plugins Vim y LSP. Busca ser una alternativa nativa a VS Code sin Electron.

```bash
# Instalación
sudo pacman -S lapce             # Arch
# O descargar binario desde: https://lapce.dev/
curl -fsSL https://github.com/lapce/lapce/releases/latest/download/lapce-linux-amd64.tar.gz | tar xzf -
./lapce
```

## Características clave

- **Nativo** — no Electron, interfaz fluida y baja latencia
- **Plugin system con WASM** — extensiones en WebAssembly
- **Vim mode** — competente, compatible con atajos básicos
- **LSP integrado** — autocompletado, diagnósticos, ir a definición
- **Editor split nativo** — múltiples paneles sin fricción
