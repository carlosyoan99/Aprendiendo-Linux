# Konsole

Terminal por defecto del entorno [[KDE Plasma]]. Potente y altamente configurable, con perfilado, pestañas, división de pantalla y perfiles de SSH guardados.

## Instalación

```bash
sudo apt install konsole          # Debian/Ubuntu
sudo pacman -S konsole            # Arch
sudo dnf install konsole          # Fedora
```

## Características

- Pestañas y splits nativos
- Perfiles de sesión guardados (SSH, directorios, comandos iniciales)
- Transparencia y blur con compositor KWin
- Integración con el tema Breeze de KDE
- Administrador de marcadores de directorios
- Búsqueda incremental en la salida
- Consumo de RAM ~30 MB

## Configuración

Se configura desde la interfaz: **Settings → Edit Current Profile**. Los perfiles se almacenan en `~/.local/share/konsole/`.
