# Atajos de teclado - GNOME Terminal y Kitty

> Accesos rápidos **por defecto** de dos terminales populares en Linux: **GNOME Terminal** (GTK, la de GNOME) y **Kitty** (GPU-accelerated, muy rápida). A diferencia de las apps de escritorio, los atajos de la terminal **dependen de la shell** (bash/zsh/fish) además de la app — ver [[La Shell]].

## Pestañas y ventanas

| Atajo | GNOME Terminal | Kitty | Efecto |
|---|---|---|---|
| `Ctrl+Shift+T` | ✓ | `Ctrl+Shift+Enter` | Nueva pestaña |
| `Ctrl+Shift+N` | ✓ | — | Nueva ventana |
| `Ctrl+Shift+W` | ✓ | — | Cerrar pestaña |
| `Ctrl+PgDn / PgUp` | ✓ | ✓ | Siguiente / anterior pestaña |
| `Ctrl+Shift+PgDn/PgUp` | ✓ | ✓ | Mover pestaña a la derecha / izquierda |
| `Ctrl+T` | Tab (terminal) | `Ctrl+Shift+Enter` igual | Dividir verticalmente |
| `Ctrl+Shift+O` | — | ✓ | Dividir vertical |
| `Ctrl+Shift+E` | — | ✓ | Dividir horizontal |
| `Ctrl+Shift+U / D` | — | ✓ | Cambiar de panel (up/down/left/right) |

## Copiar / pegar y búsqueda

| Atajo | GNOME Terminal | Kitty | Efecto |
|---|---|---|---|
| `Ctrl+Shift+C` | ✓ | ✓ | Copiar selección |
| `Ctrl+Shift+V` | ✓ | ✓ | Pegar |
| `Ctrl+Shift+F` | ✓ | ✓ | Buscar (scrollback) |
| `Ctrl+Shift+P` / `Ctrl+Shift+Y` | ✓ | ✓ | Pegado con prompt / select |

## Fuente y zoom

| Atajo | Efecto |
|---|---|
| `Ctrl+=` | Aumentar fuente |
| `Ctrl+-` | Disminuir fuente |
| `Ctrl+0` | Restablecer fuente (GNOME Terminal) |
| `Ctrl+Shift+=` / `Ctrl+Shift+-` | Zoom en Kitty |

## Otras funciones

| Atajo | GNOME Terminal | Kitty | Efecto |
|---|---|---|---|
| `F11` | ✓ | — | Pantalla completa |
| `Ctrl+Shift+L` | — | ✓ | Cambiar layout (división) |
| `Ctrl+Shift+[` / `]` | `Ctrl+Shift+` | ✓ | Siguiente / anterior ventana en Kitty |
