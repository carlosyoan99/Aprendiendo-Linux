# LibreWolf

## Qué es

**LibreWolf** es un fork de Firefox preconfigurado con privacidad máxima. Incluye uBlock Origin, desactivación de telemetría de Mozilla, resistencia a fingerprinting y motor de búsqueda por defecto privado (DuckDuckGo/Searx).

## Instalación

```bash
flatpak install flathub io.gitlab.librewolf-community
# O desde AUR:
yay -S librewolf-bin
# AppImage: https://librewolf.net/
```
