# Nemo

Gestor de archivos por defecto del entorno [[Cinnamon]]. Es un **fork de Nautilus** con más opciones y funcionalidades que su predecesor.

## Instalación

```bash
sudo apt install nemo            # Debian/Ubuntu
sudo pacman -S nemo              # Arch
sudo dnf install nemo            # Fedora
```

## Atajos clave

| Atajo | Acción |
|---|---|
| `F3` | Split panel |
| `F4` | Terminal incrustada |
| `Ctrl+T` | Nueva pestaña |
| `Ctrl+H` | Archivos ocultos |
| `F2` | Renombrar |

## Características

- Split panel (`F3`)
- Terminal incrustada (`F4`)
- Renombrado batch
- Búsqueda buena (mejor que Nautilus original)
- Soporte de complementos y scripts
- Barra de navegación estilo breadcrumb
