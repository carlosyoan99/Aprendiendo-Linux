# Nautilus (Files)

Gestor de archivos por defecto del entorno [[GNOME]]. También conocido como **GNOME Files**, es el gestor gráfico más usado en distribuciones como [[Ubuntu]], [[Fedora]] Workstation y [[Debian]] con GNOME.

## Instalación

```bash
sudo apt install nautilus        # Debian/Ubuntu
sudo pacman -S nautilus          # Arch
sudo dnf install nautilus        # Fedora
```

## Atajos clave

| Atajo | Acción |
|---|---|
| `Ctrl+H` | Mostrar/ocultar archivos ocultos |
| `Ctrl+T` | Nueva pestaña |
| `Ctrl+D` | Marcar favorito |
| `Ctrl+1` | Vista iconos |
| `Ctrl+2` | Vista lista |
| `F2` | Renombrar |

## Características

- Integración con GNOME (GTK4, tema Adwaita)
- Vista de iconos y lista
- Pestañas
- Búsqueda básica integrada
- Previsualización de archivos (imágenes, vídeo, texto)
- Extensiones vía `nautilus-*` (terminal, scripts, dropbox, nextcloud)

## Limitaciones

- Sin split panel
- Sin terminal integrada
- Sin renombrado batch nativo
