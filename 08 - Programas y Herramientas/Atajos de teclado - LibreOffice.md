# Atajos de teclado - LibreOffice

> Accesos rápidos **por defecto** de la suite ofimática **LibreOffice** (Writer, Calc, Impress). La mayoría funcionan en todas las apps de la suite. Se consultan con `Ctrl+F1` (ayuda) y se personalizan desde Herramientas → Personalizar → Teclado.

## Generales (todas las apps)

| Atajo | Efecto |
|---|---|
| `Ctrl+N` | Nuevo documento |
| `Ctrl+O` | Abrir archivo |
| `Ctrl+S` | Guardar |
| `Ctrl+Shift+S` | Guardar como |
| `Ctrl+P` | Imprimir |
| `Ctrl+Z` | Deshacer |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Rehacer |
| `Ctrl+F` | Buscar |
| `Ctrl+H` | Buscar y reemplazar |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | Copiar / Cortar / Pegar |
| `Ctrl+Shift+V` | Pegado especial (seleccionar formato) |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Negrita / Cursiva / Subrayado |
| `Ctrl+K` | Texto con enlace |
| `Ctrl+D` | Duplicar |
| `Ctrl+E` / `Ctrl+L` / `Ctrl+R` / `Ctrl+J` | Alinear centro / izquierda / derecha / justificado |
| `Ctrl+1/2/5` | Espaciado simple / 1.5 / doble |
| `F1` | Ayuda |
| `F11` | Estilos |
| `Ctrl+F11` | Navegador de estilos |
| `Ctrl+Shift+F10` | Mostrar/ocultar barras de herramientas |
| `Ctrl+Tab` | Siguiente documento abierto |
| `Ctrl+F4` | Cerrar documento actual |
| `Alt+F4` | Salir de LibreOffice |

## Writer (procesador de texto)

| Atajo | Efecto |
|---|---|
| `Ctrl+Home` / `Ctrl+End` | Inicio / fin del documento |
| `Ctrl+←` / `Ctrl+→` | Palabra anterior / siguiente |
| `Ctrl+↑` / `Ctrl+↓` | Párrafo anterior / siguiente |
| `Shift+Ctrl+↑/↓` | Seleccionar hasta inicio/fin de párrafo |
| `Ctrl+Shift+Home/End` | Seleccionar hasta inicio/fin del documento |
| `Ctrl+Enter` | Salto de página |
| `Ctrl+Shift+Enter` | Salto de columna |
| `Ctrl+M` | Eliminar formato directo |
| `Ctrl+Space` | Eliminar espacio entre palabras |
| `Ctrl+Shift+F10` | Barra de dibujo |
| `F2` | Editar texto / objeto |
| `Ctrl+Shift+N` | Estilo de párrafo predeterminado |
| `Ctrl+Shift+T` | Estilo de carácter (lista desplegable) |
| `F3` | Completar autocorrección |
| `Ctrl+F3` | Editar autocorrección |
| `Shift+F3` | Último comando de autocorrección |
| `Ctrl+Alt+Shift+C` | Comentario |
| `Ctrl+Alt+O` | Ordenar (selección) |

## Calc (hoja de cálculo)

| Atajo | Efecto |
|---|---|
| `Enter` | Confirmar celda y bajar |
| `Tab` | Confirmar celda y mover a la derecha |
| `F2` | Editar celda |
| `Ctrl+D` | Rellenar hacia abajo (copiar de arriba) |
| `Ctrl+R` | Rellenar a la derecha (copiar de la izquierda) |
| `Ctrl+L` | Insertar fórmula |
| `F4` | Dirección absoluta/relativa ($A$1 ↔ A1) |
| `Shift+F4` | Seleccionar celdas con fórmulas |
| `Ctrl+Shift+F12` | Guardar todo |
| `Ctrl+Home` | Ir a celda A1 |
| `Ctrl+End` | Ir a última celda con datos |
| `Ctrl+Space` | Seleccionar columna completa |
| `Shift+Space` | Seleccionar fila completa |
| `Ctrl+Shift+Space` | Seleccionar toda la hoja |
| `Ctrl+Page Up/Down` | Hoja anterior / siguiente |
| `Ctrl+Shift+1` | Formato número general |
| `Ctrl+Shift+5` | Formato porcentaje |
| `Ctrl+` | Zoom |
| `Ctrl+-` | Zoom reducido |
| `Ctrl+Shift+G` | Ir a celda (caja de diálogo) |
| `F11` | Navegador de estilos de celda |
