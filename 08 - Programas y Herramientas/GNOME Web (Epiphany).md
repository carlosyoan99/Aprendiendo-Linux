# GNOME Web (Epiphany)

## Qué es

**GNOME Web** (también conocido como Epiphany) es el navegador nativo de GNOME. Usa el motor **WebKit** (el mismo de Safari). Es ligero, está integrado con el escritorio GNOME y consume menos recursos que Chromium o Firefox.

## Instalación

```bash
sudo apt install epiphany-browser        # Debian/Ubuntu
sudo pacman -S epiphany                  # Arch
```
