# Atajos de teclado - Editores Kate y Gedit

> Accesos rápidos **por defecto** de los editores de texto de escritorio **Kate** (KDE/Qt) y **Gedit** (GNOME/GTK). Ambos comparten la mayoría de atajos GTK/Qt estándar. Se editan en Configuración → Atajos de teclado.

## Abrir / guardar / cerrar

| Atajo | Kate | Gedit | Efecto |
|---|---|---|---|
| `Ctrl+N` | ✓ | ✓ | Nuevo documento |
| `Ctrl+O` | ✓ | ✓ | Abrir archivo |
| `Ctrl+S` | ✓ | ✓ | Guardar |
| `Ctrl+Shift+S` | ✓ | ✓ | Guardar como |
| `Ctrl+W` | ✓ | ✓ | Cerrar pestaña |
| `Ctrl+Q` | ✓ | ✓ | Salir |
| `Ctrl+Tab` | ✓ | — | Siguiente pestaña |
| `Ctrl+Shift+Tab` | ✓ | — | Pestaña anterior |

## Edición y selección

| Atajo | Efecto |
|---|---|
| `Ctrl+Z` / `Ctrl+Shift+Z` | Deshacer / Rehacer |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Cortar / Copiar / Pegar |
| `Ctrl+A` | Seleccionar todo |
| `Ctrl+D` | **Kate**: duplicar línea actual (**Gedit**: borrar línea, configurable) |
| `Ctrl+Shift+D` | Gedit: duplicar línea |
| `Ctrl+Shift+K` | **Kate**: borrar línea actual |
| `Ctrl+Shift+↑/↓` | Mover línea arriba/abajo (Kate) |
| `Ctrl+Alt+↑/↓` | **Kate**: duplicar línea arriba/abajo |
| `Ctrl+Home` / `Ctrl+End` | Ir al inicio / fin del documento |
| `Home` / `End` | Inicio / fin de línea |
| `Ctrl+←` / `Ctrl+→` | Saltar palabra anterior / siguiente |
| `Ctrl+Shift+Espacio` | **Kate**: autocompletar |

## Búsqueda y reemplazo

| Atajo | Efecto |
|---|---|
| `Ctrl+F` | Buscar |
| `Ctrl+H` | **Kate**: reemplazar (**Gedit**: búsqueda con reemplazo alta) |
| `Ctrl+G` | Ir a línea |
| `F3` | Siguiente resultado de búsqueda |
| `Shift+F3` | Resultado anterior |
| `Ctrl+I` | Buscar en archivos (Kate) |

## Formato y ventanas

| Atajo | Kate | Efecto |
|---|---|---|
| `Ctrl+T` | ✓ | Nueva pestaña de Terminal integrada |
| `Ctrl+Shift+P` | ✓ | Paleta de comandos rápida |
| `F11` | ✓ | Modo pantalla completa |
| `Ctrl+Shift+F` | Gedit | Búsqueda en todo el documento |
