# Atajos de teclado - VSCode

> Accesos rápidos **por defecto** de Visual Studio Code (Linux). La mayoría son idénticos en **VSCodium, Codium y Zed**. Se consultan y personalizan con `Ctrl+K Ctrl+S` (Atajos de teclado). `CTRL+SHIFT+P` abre la paleta de comandos, la puerta a casi todo.

## Paleta de comandos y búsqueda

| Atajo | Efecto |
|---|---|
| `Ctrl+Shift+P` / `F1` | Paleta de comandos |
| `Ctrl+P` | Ir a archivo por nombre (salto rápido) |
| `Ctrl+Shift+F` | Buscar en todos los archivos |
| `Ctrl+Shift+H` | Reemplazar en todos los archivos |
| `Ctrl+Shift+E` | Explorador (barra lateral de archivos) |
| `Ctrl+Shift+U` | Salida (output) |
| `Ctrl+Shift+G` | Control de versiones (Git) |
| `Ctrl+Shift+X` | Extensiones |
| `Ctrl+,` | Ajustes (Settings) |
| `Ctrl+K Ctrl+S` | Atajos de teclado (preferencias) |

## Edición

| Atajo | Efecto |
|---|---|
| `Ctrl+S` | Guardar |
| `Ctrl+Shift+S` | Guardar como |
| `Ctrl+Z` / `Ctrl+Y` | Deshacer / Rehacer |
| `Ctrl+F` | Buscar en el archivo |
| `Ctrl+H` | Reemplazar en el archivo |
| `F2` | Renombrar símbolo (toda la base de código) |
| `Ctrl+D` | Seleccionar siguiente coincidencia (multicursor) |
| `Ctrl+Shift+L` | Seleccionar todas las coincidencias |
| `Alt+↑` / `Alt+↓` | Mover línea arriba / abajo |
| `Alt+Shift+↑/↓` | Duplicar línea |
| `Ctrl+Shift+K` | Borrar línea |
| `Ctrl+/` | Alternar comentario de línea |
| `Shift+Alt+A` | Alternar comentario de bloque |
| `Ctrl+Shift+↵` | Abrir línea debajo |
| `Ctrl+Alt+↑/↓` | Añadir cursor arriba / abajo |

## Selección y navegación

| Atajo | Efecto |
|---|---|
| `Ctrl+Shift+O` | Ir a símbolo (dentro del archivo) |
| `Ctrl+T` | Ir a símbolo en todo el workspace |
| `Ctrl+G` | Ir a línea |
| `Ctrl+Tab` | Cambiar entre archivos abiertos |
| `Ctrl+\` | Dividir editor (split) |
| `Ctrl+1 / 2 / 3` | Activar editor 1 / 2 / 3 |
| `Ctrl+B` | Mostrar/ocultar barra lateral |
| `Ctrl+J` | Alternar panel inferior |
| `Ctrl+`+` | Abrir/cerrar terminal integrada |
| `Ctrl+Shift+M` | Panel de problemas (diagnósticos) |

## Depuración y ejecución

| Atajo | Efecto |
|---|---|
| `F5` | Iniciar depuración |
| `Shift+F5` | Detener depuración |
| `F9` | Alternar breakpoint |
| `F10` | Paso a paso (step over) |
| `F11` | Entrar (step into) |
| `Shift+F11` | Salir (step out) |
| `Ctrl+Shift+D` | Vista de depuración |
| `Ctrl+F5` | Ejecutar sin depurar |
