# Motif

> Toolkit de widgets GUI histórico para Unix. Base del Common Desktop Environment (CDE) y estándar en sistemas comerciales Unix de los 90s.

## Qué es

**Motif** (o LessTif como implementación libre) fue el toolkit de interfaz gráfica más usado en Unix comercial durante los 90s. Proporcionaba widgets (botones, menús, ventanas) con el aspecto característico de la época. Su implementación en software libre es **Lesstif**, aunque también existe **Open Motif** (liberado por IBM bajo LGPL).

## Componentes

| Componente | Función |
|---|---|
| **Xm (Motif toolkit)** | Widgets básicos (botones, menús, scrollbars) |
| **Mrm (Motif Resource Manager)** | Carga de interfaces desde archivos UID |
| **UIL (User Interface Language)** | Lenguaje para definir interfaces |
