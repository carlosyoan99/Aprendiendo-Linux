# date y timedatectl

> `date` es el comando clásico de fecha/hora. `timedatectl` es la herramienta moderna de systemd para gestionar la zona horaria, NTP y el reloj hardware (RTC).

## Notas individuales

- [[date]] — mostrar/establecer fecha, formato personalizado, timestamp Unix
- [[timedatectl]] — zona horaria, NTP, RTC, diagnóstico de hora
