# 7z

> Herramienta de línea de comandos del archivero **7-Zip**, el formato `.7z` con la mejor compresión del mercado (ratio alta, algoritmo LZMA2). Portable y multiplataforma.

## Sintaxis

```
7z <comando> [opciones] <archivo.7z> [archivos...]
```

El primer argumento es un **comando** (no una subopción): `a` (añadir/crear), `x` (extraer con rutas), `e` (extraer sin rutas), `l` (listar), `t` (test), `u` (actualizar), `d` (borrar).

## Descripción

`7z` es el ejecutable CLI del proyecto 7-Zip (open source, originalmente de Igor Pavlov). Soporta los formatos `.7z`, `.zip`, `.tar`, `.gzip`, `.bzip2`, `.xz` y otros. Su gran ventaja es la **máxima compresión** frente a `zip`/`gzip` (el ratio `.7z` suele ser 30-70% más pequeño que `.zip`), a costa de velocidad y memoria.

Utiliza **LZMA2** (o LZMA) como algoritmo de compresión por defecto, con soporte para compresión sólida y diccionarios grandes. En Linux viene del paquete `p7zip` (7-Zip POSIX).

## Instalación

```bash
# Debian / Ubuntu / derivadas
sudo apt install p7zip-full

# Arch Linux / CachyOS
sudo pacman -S p7zip

# Fedora / RHEL
sudo dnf install p7zip p7zip-plugins
```

## Comandos principales

| Comando | Acción | Ejemplo |
|---|---|---|
| `a` | Añadir / crear archivo | `7z a backup.7z datos/` |
| `x` | Extraer conservando rutas | `7z x backup.7z` |
| `e` | Extraer aplanando (sin rutas) | `7z e backup.7z` |
| `l` | Listar contenido | `7z l backup.7z` |
| `t` | Probar integridad | `7z t backup.7z` |
| `d` | Borrar entradas | `7z d backup.7z viejo.txt` |

## Opciones útiles

| Opción | Efecto |
|---|---|
| `-9` | Máxima compresión |
| `-mx=9` | Idem, nivel de compresión 0-9 |
| `-p` | Pedir contraseña (cifrado AES-256) |
| `-t7z` | Forzar formato `.7z` |
| `-tzip` | Forzar formato `.zip` |
| `-o<dir>` | Directorio de salida (junto a `-x`) |
| `-slt` | Listado técnico detallado |

## Ejemplos

```bash
# Crear un archivo .7z con máxima compresión
7z a -mx=9 proyecto.7z proyecto/

# Crear un .zip encriptado con contraseña
7z a -tzip -p secreto.zip documento.txt

# Extraer todo en un directorio concreto
7z x backup.7z -o/restauracion/

# Comprobar la integridad de un backup
7z t backup.7z
```

## Casos de uso

- **Backups con ratio máximo**: comprimir carpetas grandes al mínimo espacio posible.
- **Encriptar archivos**: con `-p` se cifran con AES-256 (mejor que el cifrado débil de `.zip`).
- **Distribuir en Windows**: 7-Zip es estándar en Windows; un `.7z` se abre sin herramientas extra.

Para compresión rápida y universal a corto plazo, `zip` es más compatible; para **ratio de compresión máximo** en backups, `7z -mx=9` es superior.
