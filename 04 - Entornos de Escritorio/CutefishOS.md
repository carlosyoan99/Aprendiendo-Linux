# CutefishOS

> DE Wayland con estética macOS-like. Dock inferior, barra superior, animaciones fluidas. Basado en Qt5 + KDE Frameworks.

## Qué es

CutefishOS es un entorno de escritorio que busca replicar la estética de macOS en Linux: dock inferior, barra de estado superior, centering de ventanas, y animaciones suaves. Usa Qt5 y KDE Frameworks.

## Características

| Aspecto | Detalle |
|---|---|
| **Toolkit** | Qt5 + KDE Frameworks |
| **Compositor** | KWin (Wayland) |
| **Estilo** | macOS-like (dock, barra superior) |
| **Base** | Ubuntu (distro propia) |

## Requisitos

- GPU con soporte Wayland
- Mínimo 2GB RAM
- 20GB disco
