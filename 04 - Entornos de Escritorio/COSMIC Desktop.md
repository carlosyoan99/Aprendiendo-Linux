# COSMIC Desktop

> DE Wayland construido desde cero en Rust por System76. Modular, seguro en memoria, con gestor de ventanas propio (COSMIC Comp).

## Qué es

COSMIC es el nuevo entorno de escritorio de System76 (los creadores de Pop!_OS). Reemplaza GNOME en Pop!_OS. Escrito completamente en Rust usando el toolkit ICD (Iced), es modular y nativo Wayland.

| Aspecto | Detalle |
|---|---|
| **Lenguaje** | Rust |
| **Toolkit** | Iced |
| **Compositor** | COSMIC Comp (Wayland) |
| **Barra** | COSMIC Panel (Rust) |
| **App Store** | COSMIC Store (Flathub integration) |
| **Configuración** | COSMIC Settings (Rust) |

## Características clave

- **Modular**: cada componente es un binario independiente
- **Tiling + Floating**: gestor de ventanas híbrido
- **Workspaces**: gestión nativa de espacios de trabajo
- **Accesibilidad**: soporte temprano pero activo
- **Flathub**: integración directa con Flatpak

## Estado actual

- Beta pública disponible (2025-2026)
- Sera el DE por defecto de Pop!_OS 24.04
- Se puede probar en cualquier distro con Wayland
