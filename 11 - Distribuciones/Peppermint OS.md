# Peppermint OS

> Distribución Linux ligera que combina aplicaciones locales con **SSBs (Site-Specific Browsers)** para crear una experiencia híbrida web-escritorio. Basada en Debian con escritorio XFCE.

## Filosofía / público objetivo

Peppermint OS fue creada en 2010 con un enfoque único: en lugar de incluir aplicaciones nativas pesadas, muchas herramientas se integran como **SSBs** (accesos directos web que parecen aplicaciones nativas) mediante su herramienta **Ice**. Esto la hace extremadamente ligera en recursos.

## Características clave

| Aspecto | Detalle |
|---|---|
| **Base** | Debian (versiones iniciales: Lubuntu) |
| **Gestor de paquetes** | APT + Snap + Flatpak |
| **Init** | systemd |
| **Modelo** | Fixed release |
| **Entorno por defecto** | XFCE (antes LXDE) |
| **Herramienta estrella** | Ice (crea SSBs web) |

### Herramientas propias

- **Ice**: crea accesos directos tipo aplicación para servicios web (Gmail, YouTube, Google Docs) que se abren sin la interfaz completa del navegador
- **Welcome to Peppermint**: asistente post-instalación para instalar paquetes, temas y navegadores
- **Peppermint Hub**: acceso centralizado a configuraciones del sistema
